# invoice-web MVP PRD

## 핵심 정보

**목적**: 사업주가 Notion에서 관리하는 견적서를 클라이언트(고객)가 별도 계정 없이 고유 링크로 웹에서 확인하고 PDF로 다운로드할 수 있게 한다.
**사용자**: 프리랜서/소규모 사업주(관리자)와 해당 고객(클라이언트)

---

## 사용자 여정

### 관리자 여정

```
1. 로그인 페이지
   ↓ 관리자 이메일/비밀번호 입력 후 로그인

2. 인보이스 목록 페이지
   ↓ 인보이스 항목 클릭

3. 인보이스 상세 페이지 (관리자 뷰)
   ↓ '공유 링크 복사' 버튼 클릭
   → 클립보드에 클라이언트 전용 공개 URL 복사됨
   ↓ '새 인보이스' 버튼 클릭 (목록 페이지에서)

4. 인보이스 생성 페이지
   ↓ 폼 입력 후 저장
   → Notion DB에 저장 → 목록 페이지로 이동

   ↓ 목록에서 인보이스 클릭 → 상세 페이지
   ↓ '편집' 버튼 클릭

5. 인보이스 편집 페이지
   ↓ 내용 수정 후 저장
   → Notion DB 업데이트 → 상세 페이지로 이동
```

### 클라이언트 여정

```
1. 클라이언트는 사업주에게 고유 URL을 이메일/메시지로 전달받음
   ↓ 브라우저에서 URL 접속 (로그인 불필요)

2. 클라이언트 견적서 뷰 페이지
   ↓ 견적서 내용 확인
   ↓ 'PDF 다운로드' 버튼 클릭

3. 브라우저 PDF 저장 완료
```

| **F002** | 인보이스 상세 조회 (관리자) | Notion 페이지 ID로 단일 인보이스 전체 정보 조회                 | 공유 링크 생성 및 편집 진입점                        | 인보이스 상세 페이지        |
| **F003** | 인보이스 생성               | Notion DB에 새 인보이스 페이지 생성                             | 핵심 데이터 입력 기능                                | 인보이스 생성 페이지        |

| **F005** | 공개 링크 공유              | 인보이스 ID 기반 클라이언트 전용 공개 URL 생성 및 클립보드 복사 | 클라이언트에게 견적서 전달하는 유일한 수단           | 인보이스 상세 페이지        |
| **F006** | 클라이언트 견적서 뷰        | 인증 없이 고유 URL로 접근 가능한 읽기 전용 견적서 화면          | 프로젝트의 핵심 가치 — 고객이 견적서를 확인하는 기능 | 클라이언트 견적서 뷰 페이지 |
| **F007** | PDF 다운로드                | 클라이언트가 견적서를 브라우저 인쇄/PDF 저장으로 다운로드       | 고객이 견적서를 보관·서명하기 위한 필수 기능         | 클라이언트 견적서 뷰 페이지 |

### 2. MVP 필수 지원 기능

| ID       | 기능명      | 설명                                                   | MVP 필수 이유                                                 | 관련 페이지   |
| -------- | ----------- | ------------------------------------------------------ | ------------------------------------------------------------- | ------------- |
| **F010** | 관리자 인증 | 이메일/비밀번호 로그인 및 로그아웃 (Next.js 세션 기반) | 관리자만 인보이스를 생성·편집·공유할 수 있도록 접근 제어 필요 | 로그인 페이지 |

- 인보이스 삭제 (Notion 아카이브는 구현되어 있으나 UI 노출 제외)
- 이메일 자동 발송
- 인보이스 번호 자동 채번
- 다국어 / 통화 선택
- 클라이언트 서명 기능

## 페이지별 상세 기능

### 로그인 페이지

> **구현 기능:** `F010` | **인증:** 불필요 (비로그인 접근 가능)

| 항목            | 내용                                                                                                             |
| --------------- | ---------------------------------------------------------------------------------------------------------------- |
| **역할**        | 관리자 전용 인증 페이지                                                                                          |
| **진입 경로**   | 직접 접속, 또는 인증이 필요한 관리자 페이지 접근 시 자동 리디렉션                                                |
| **사용자 행동** | 이메일과 비밀번호를 입력하고 로그인 버튼을 클릭한다                                                              |
| **주요 기능**   | • 이메일/비밀번호 입력 폼 (React Hook Form + Zod 검증)<br>• 로그인 실패 시 에러 메시지 표시<br>• **로그인** 버튼 |
| **다음 이동**   | 성공 → 인보이스 목록 페이지, 실패 → 에러 메시지 표시 후 현 페이지 유지                                           |

| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **역할**        | 클라이언트가 별도 계정 없이 고유 URL로 견적서를 확인하고 PDF로 저장하는 공개 페이지                                                                                                                                                           |

| **다음 이동**   | PDF 다운로드 완료 → 동일 페이지 유지                                                                                                                                                                                                          |

## 데이터 모델

### Invoice (Notion DB 페이지)

| 필드          | 설명                             | 타입/관계                        |
| ------------- | -------------------------------- | -------------------------------- |
| id            | Notion 페이지 UUID               | UUID                             |
| invoiceNumber | 인보이스 번호 (예: INV-2025-001) | Title                            |
| clientName    | 고객사 이름                      | Rich Text                        |
| amount        | 청구 금액                        | Number                           |
| status        | 인보이스 상태                    | Select (Draft/Sent/Paid/Overdue) |
| issueDate     | 발행일                           | Date                             |
| dueDate       | 만기일                           | Date                             |
| email         | 고객 이메일                      | Email                            |
| notes         | 비고                             | Rich Text                        |

> 별도 DB 테이블 없음. Notion이 단일 데이터 소스 역할을 함.

## 기술 스택 (현재 버전)

### 프론트엔드 프레임워크

- **Next.js 15.5.3** (App Router + Turbopack) - React 풀스택 프레임워크
- **TypeScript 5** - 타입 안전성 보장
- **React 19.1.0** - UI 라이브러리

### 스타일링 & UI

- **TailwindCSS v4** (설정 파일 없는 새로운 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** (new-york style) - 고품질 React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리

### 폼 & 검증

- **React Hook Form 7.x** - 폼 상태 관리
- **Zod** - 스키마 검증 라이브러리
- **Server Actions** - 서버사이드 폼 제출 처리

### 백엔드 & 데이터베이스

- **@notionhq/client v5** - Notion API SDK (데이터 소스)
- **Notion Database** - 인보이스 데이터 저장소 (별도 DB 불필요)

### 배포 & 호스팅

- **Vercel** - Next.js 15 최적화 배포 플랫폼

### 패키지 관리

- **npm** - 의존성 관리
